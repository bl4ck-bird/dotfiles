# 구현자에게 전달할 내용

메인은 실제 작업에 맞게 다음 내용을 짧은 배정으로 전달한다. 사용하지 않는 항목을 빈 양식으로 남기지 않는다.

- 이번 작업의 목표와 전체에서의 위치
- 먼저 읽을 배정 파일·기준 명세·관련 설계 계약
- 편집할 범위와 기존 사용자 변경, 실제 작업 디렉터리
- 검증 명령·환경·수용 결과, 커밋 등 허용된 전달 범위
- 보고 파일 위치와 반환할 짧은 상태
- 추가 에이전트 호출 금지, 공유 상태는 메인 소유

구현자는 계약에 모순이나 중요한 공백이 있으면 추측하지 말고 보고한다. 승인 범위에서 구현·검증·자기 검토를 마치고 파일 변경·실제 검사 결과·우려를 보고 파일에 남긴다. 테스트나 리뷰를 수행하지 않았다면 그대로 적는다. 반환 메시지는 상태·결과·검증 요약·우려와 보고 경로만 포함한다.
