# 라이선스 안내

bl4ck-harness의 새 작성 부분은 MIT 라이선스로 제공한다. Superpowers와 Matt Pocock의 지침을 바탕으로 한 부분의 원 저작권·허가·면책 고지를 함께 보존한다.

사용·복제·수정·배포를 허용하되 저작권과 허가 고지를 유지해야 하며 무보증으로 제공한다. 이는 편의를 위한 한글 설명이고 아래 원문이 적용된다. 사용자가 요청한 한글 문서 원칙의 예외로 법적 고지 원문을 그대로 보존한다.
