# Integration and UI Verification

요청을 시작하는 행동→관련 경계→상태 변화→관찰 결과를 연결한다. 단위 구성 요소 통과만으로 전체 흐름을 완료로 처리하지 않는다.

## Evidence Selection

- 코드·공유 상태·설정과 실제 호출·데이터 흐름의 연결을 확인한다.
- 필요한 통합 검사와 실제 상호작용을 선택한다. 대체된 서비스·mock·실행 환경을 명시하고 해당 범위 이상의 검증을 주장하지 않는다.
- UI 동작은 재현 행동·기대/실제 결과·환경·증거를 기록하고 수정 후 같은 흐름을 확인한다. 스크린샷만으로 런타임 동작을 입증하지 않는다.
- 시각적 판단이나 접근할 수 없는 필수 환경은 사용자 확인으로 남기고, 자동으로 확인 가능한 항목까지 일괄 수동 검토로 넘기지 않는다.
- 관련 실패·중단·재시도 결과도 승인된 계약과 대조한다. 실행하지 못한 필수 검사는 미검증으로 남긴다.

기존 계획·리뷰·완료 기록에 연결하고 별도 점수나 모든 기능의 일괄 브라우저 검사를 요구하지 않는다.
