# Focused Re-review

## Inputs

이전 대상·기존 지적 사항과 해결 조건·수정된 대상·수정 범위·검증 결과. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 각 기존 지적 사항이 해결됐는지, 남았는지, 판단 불가인지 근거로 구분했는가?
- 수정이 새 회귀·모순·검증 공백을 만들지 않았는가?
- 영향받는 호출자·소비자·관련 문서까지 확인했는가?
- 수정 후에도 승인 범위와 필수 검사·이전 근거가 유효한가?

## Scope

이전 ID·보고·수정 한도를 유지한다. 문서 검토에 코드 커밋이나 미래 구현 승인을 요구하지 않는다. 무관한 기존 문제는 분리하고 근거 없이 전체 리뷰를 재시작하지 않는다.
