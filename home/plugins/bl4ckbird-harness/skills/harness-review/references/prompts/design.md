# System Design Review

## Inputs

승인된 방향·요구·제약·현재 구조·제안 설계·결정·가정 검증 자료. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 주요 설계가 요구·제약·위험에서 도출됐는가? 기존 구조 재사용과 대안의 장단점이 타당한가?
- 책임·의존 방향·데이터 소유가 명확하고 핵심 불변식에 책임자와 보장 방법이 있는가?
- 정상·중요 실패·복구 흐름이 구성 요소 사이에서 실제로 연결되는가?
- 구조 성립을 좌우하는 스키마·트랜잭션·인터페이스·운영 가정을 필요한 깊이로 확인했는가?
- 미룬 질문에 해결 시점·재검토 조건이 있으며 후속 구현자가 중요한 구조를 새로 정할 공백이 없는가?

## Scope

아직 구현하지 않은 제품의 테스트 통과를 설계 증거로 요구하지 않는다. 관련 책임·계약은 코드 품질 기준, 보안·실패 경계는 해당 조건부 참조를 함께 적용한다.
