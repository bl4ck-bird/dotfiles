# Final Review

## Inputs

합의한 결과물 전달 지점·실제 통합 대상·수용 기준·리뷰 해결 근거·검증·문서·사용자 확인 상태. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 통합된 결과가 각 수용 기준을 충족하며 필수 검증·독립 리뷰의 근거가 현재 대상에 유효한가?
- 실패·미검증·사용자 확인 대기를 전체 완료로 숨기지 않았는가?
- 현재 설계·로드맵·사용자 문서가 실제 구현 위치와 일치하며 내부 기록이 제품에 노출되지 않는가?
- 허용된 전달·정리 범위와 실제 결과가 맞고 외부 작업의 불확실한 결과를 안전한 재시도로 오해하지 않았는가?

## Scope

별도 최종 리뷰가 배정됐을 때만 사용한다. 파일 존재만으로 모든 완료 작업에 추가 리뷰를 강제하거나 모든 결과를 배포까지 요구하지 않는다.
