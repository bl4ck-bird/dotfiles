# Roadmap Review

## Inputs

승인된 비전·설계·요구·성과 목록·순서·의존 관계·진행 중 작업. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 각 요구를 실현할 성과와 확인 가능한 완료 조건이 있는가?
- 숨은 의존성·순환·이미 진행 중인 작업과의 충돌이 없는가?
- 큰 위험을 너무 늦게 검증하거나 성과 없는 기반 작업을 먼저 과도하게 쌓지 않는가?
- 추정을 확정 일정으로 표시하거나 재정렬 과정에서 범위·수용 기준을 조용히 바꾸지 않았는가?
- 다음 상세 명세의 범위·선행 조건·미결정이 명확한가?

## Scope

전체 로드맵을 구현 태스크로 세분화하거나 고정 단계 수·일정을 요구하지 않는다. 실행 중 내부 순서 조정과 성과 우선순위 변경을 구분한다.
