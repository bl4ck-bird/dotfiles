# Implementation Review

## Inputs

승인된 명세·계획·실제 코드 변경·관련 호출자·검증 대상과 결과. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 실제 동작이 승인된 정상·실패·상태·호환성 계약을 만족하는가?
- 단위 검사뿐 아니라 슬라이스의 연결된 동작과 필요한 통합·UI 결과가 입증되는가?
- 책임·타입·오류·주석과 관련 동시성·자원 수명·정밀도·부하에 회귀나 유지보수 문제가 있는가?
- 테스트·fixture·mock·설정 변경이 실제 결함을 숨기거나 필수 검증을 약화하지 않았는가?
- 코드·주석·테스트·문서·커밋/PR 제안에 내부 ID·작업 문서 참조가 노출되지 않는가?

## Scope

승인된 동작·품질 문제에 집중한다. 요구 변경이 필요하면 구현 수정으로 숨기지 않는다. 무관한 기존 문제와 형식 취향을 필수 수정에 섞지 않는다.
