# Record Retention

완료한 작업은 원래 `work/<work-id>/` 경로를 유지하고 활성 탐색 목록만 정리한다. 승인 대상·결정·리뷰·검증·재시도·중단 후 재개 근거를 보존한다.

## Before Cleanup

작업 공간 정리 전에 다음을 확인한다.

- 실제 경로·저장소·브랜치·생성 이력과 유효한 정리 권한.
- 관련 에이전트·테스트·개발 서버의 종료와 후속 작업의 공간 필요 여부.
- 승인된 통합 대상에 반영되거나 보존된 코드, 기준 위치에 회수된 필수 근거.
- 추적·미추적·Git 무시 파일에 잃게 될 고유 변경이 없는지.

보존 사본은 파일 목록과 내용을 대조한다. 캐시·중복 입력과 유일한 판단 근거인 로그·스크린샷을 구분한다. 불확실한 대상만 보류한다.

## Results and Resumption

기존 작업 기록에 대상·정리 권한·보존 위치·제거/보존/실패 결과를 남긴다. [정상 제거](delivery.md#cleanup)가 중단되면 실제 경로와 Git 등록을 확인하고 남은 단계만 처리한다. 대상이 사라졌다는 사실을 필수 근거 보존의 증거로 쓰지 않는다.
