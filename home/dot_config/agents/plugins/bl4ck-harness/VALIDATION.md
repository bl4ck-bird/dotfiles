# 검증 범위

2026년 9월 22일 이름 변경과 Superpowers 6.4.1 선택 반영 소스 기준이다.

## 실행한 검사

| 검사 | 결과 | 확인 범위 |
| --- | --- | --- |
| Codex 제공 플러그인 검사 도구 | 통과 | 매니페스트 계약과 스킬 메타데이터 |
| Codex 제공 스킬 검사 도구 | 20개 통과 | 스킬 이름·메타데이터·기본 형식 |
| `python3 -B scripts/validate.py` | 통과 | 20개 호출 이름·참조·한글 제목·캐시 갱신 버전 |
| `python3 -B -m unittest discover -s tests -q` | 26개 통과, 건너뜀 없음 | 초기화·자료 보존·경로 경계·사본·Git 제외·문서 링크·상태 모순 |
| 작성자와 다른 에이전트의 독립 검토 | 통과 | 이름 일관성, 저위험 인라인과 고위험 공유 계약 변경의 규칙 추적, 수정 후 재리뷰, 최종 검사와 Markdown 상태 유지 |

기록 도구 검증은 임시 디렉터리와 임시 Git 저장소에서 실행했다. 기존 제외 규칙·CURRENT·다른 하네스 자료를 보존하고, 비활성·잘못된 설정과 경로 이탈을 거부하는지 확인한다. 원본 변경 후에도 사본을 보존하며 상태의 완료 모순·미확인 실행·활성 링크 누락을 검사한다. 과거 자유형식 기록과 스냅샷을 자동 변환하지 않는다.

중첩 코드 블록의 가짜 링크를 실제 참조로 읽는 실패를 먼저 재현한 뒤 수정했다. backtick·tilde 코드 예시를 건너뛰면서 블록 밖 실제 누락 링크는 계속 거부하는 회귀 검사가 통과했다. 참조형 활성 링크는 지원하지 않으며 오류에서 인라인 예시를 안내한다.

Codex 설치 캐시의 버전명 디렉터리도 같은 패키지로 검사하며, 소스와 캐시 레이아웃에서 잘못된 매니페스트 이름은 거부하는 회귀 검사가 통과했다.

## 한계

형식 검사와 시나리오 규칙 추적은 실제 모델 성능·비용·속도의 평가가 아니다. 자유로운 검증 문장의 진실성, 실제 호스트 실행 종료, 장기 작업과 압축 후 복구는 자동 검증하지 않는다. 설치 여부는 현재 호스트에서 별도로 확인하며, 새 세션에서 `$using-bl4ck-harness`의 탐색·참조 읽기를 확인한다. 항상 주입되는 시작 훅은 제공하지 않는다.
