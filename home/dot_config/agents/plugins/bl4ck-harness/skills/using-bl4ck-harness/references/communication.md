# 대화와 결정 진행

한국어로 결론·근거·다음 행동을 명료하게 전달한다. 하네스 지침과 작업 문서는 제목·표 열을 포함해 한글로 쓴다. 기술 식별자·명령·기계 키·원문 오류는 보존한다. 제품 결과물에는 프로젝트 언어를 적용한다.

## 질문

- 여러 결정을 논의하기 전에 현재 확인한 주제 목록을 짧게 알린다. 질문 제목에 `저장 방식 (2/5)`처럼 현재 주제와 전체 주제 수를 표시한다.
- 같은 주제의 보충 질문은 번호를 유지한다. 새 주제가 생기면 전체 개수와 추가 이유를 알린다. 전체가 잠정이면 잠정이라고 말한다. 질문 위치를 완료 개수로 표시하지 않는다.
- 질문마다 결정 이유와 추천안을 짧게 제시한다. 저장소·문서로 확인할 사실을 사용자에게 떠넘기지 않는다. 질문 도구의 제목에도 진행 번호를 넣는다.
- 중요한 선택을 한 번에 이해하기 쉬운 크기로 묻는다. 독립적이고 짧은 선택은 묶을 수 있다. 질문 개수를 맞추거나 모든 문단마다 승인을 요구하지 않는다.
- 승인 범위에서 진행 가능한 작업은 이어 간다. 이미 답한 결정을 반복해서 묻지 않으며, 바뀐 근거가 영향을 주는 부분만 재논의한다.

## 보고

진행은 새 사실·불확실성·다음 행동, 검토는 지적 사항·근거·미검증·판정, 완료는 결과·검증·남은 문제·전달 상태를 담는다. 빈 형식이나 작업 일지를 대화에 반복하지 않는다. 최종 답변은 이전 진행 보고를 열지 않아도 이해할 수 있게 쓴다.
