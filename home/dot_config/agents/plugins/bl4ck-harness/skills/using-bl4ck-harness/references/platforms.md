# 실행 환경과 진입

## Codex 환경

이 패키지는 `.codex-plugin/plugin.json`과 기본 스킬 탐색을 사용한다. 새 세션이나 작업 재개에서 `$using-bl4ck-harness`을 명시적으로 호출하면 진입 규칙을 읽고 시작한다. 관련 설명에 따라 자동 선택될 수도 있지만 설치·설명만으로 항상 실행되거나 압축 후 자동 주입된다고 보장하지 않는다. 이 패키지는 검증되지 않은 시작 훅을 등록하지 않는다.

호스트의 실제 파일 읽기·실행·위임·대기 도구를 사용한다. 존재하지 않는 Skill 도구나 에이전트 API를 흉내 내지 않는다. 스킬 호출 도구가 없으면 해당 SKILL.md와 필요한 참조를 읽어 적용한다. 독립 위임이 없으면 인라인 구현은 가능하나 독립 리뷰를 자기 검토로 대체해 통과 처리할 수 없다.

## 선택과 공존

프로젝트 적용은 `.harness/config.json`의 `plugin: "bl4ck-harness"`, `schema_version: 1`, `enabled: true`로 확인한다. 파일이 없거나 비활성이면 자동으로 전체 절차를 적용하지 않는다. 명시적인 개별 스킬 요청은 해당 작업에만 적용할 수 있다. 기록이 필요한 작업에서 초기화 권한이 없다면 먼저 필요한 결과를 대화로 정리하고 적용 범위만 확인한다.

다른 하네스 설정·기록을 발견하면 존재만으로 bl4ck-harness 기록이라고 간주하지 않는다. 기존 `.harness/config.toml` 등은 자동 변환·삭제하지 않는다. 사용자가 bl4ck-harness을 선택해 필요한 이관 범위를 정해야 한다. 원본 Superpowers와 함께 설치된 경우 한 작업의 절차 담당을 분명히 하고 같은 단계의 원본·변형판을 중복 호출하지 않는다.

전역 AGENTS.md는 대화·안전 등 일반 선호만 둔다. 프로젝트별 제품 규칙과 호스트의 상위 지침을 존중한다. 하네스 규칙을 전역 파일에 복사하지 않는다. 진입점을 거치지 않는 개별 스킬에도 공통 참조를 연결해 두었으며, 읽기 여부를 확인한다.
