# 병행 작업 배정

작업을 병행하지 않아도 충분하면 그대로 진행한다. 공유 파일·인터페이스·데이터·테스트 포트·외부 효과를 확인한다. 같은 원인의 오류나 한 결정을 공유하는 작업은 먼저 함께 조사한다.

독립적인 조사·검토는 읽기 범위와 질문을 구분해 배정한다. 구현 병행은 사용 가능한 위임 권한과 격리된 편집 범위, 사전 합의한 공유 계약, 통합 담당자와 순서가 있을 때만 수행한다. 파일이 겹치지 않는다는 사실만으로 충분하지 않다.

각 배정에 최소 근거·명확한 결과·허용된 수정·보고 위치를 전달하고 추가 위임을 금지한다. 공유 상태는 메인이 관리한다. 기다리면서 가능한 로컬 작업을 수행하고 이벤트 기반 결과 수신을 우선한다.

모든 결과의 실제 종료와 변경을 확인하고 통합한다. 각 작업의 검사 통과가 통합 통과를 대신하지 않는다. 불확실한 실행을 중복 배정하지 않는다.
