# Discovery Review

## Inputs

요청·문제 탐색 결과·기존 비전·관련 근거·명시한 제약. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 실제 문제와 대상 사용자가 근거로 설명되는가? 만들지 않거나 기존 기능을 활용하는 선택도 검토했는가?
- 성공 기준·핵심 흐름·포함/제외 범위가 서로 맞는가?
- 미검증 가정을 사실로 취급하거나 중요한 대안을 근거 없이 배제하지 않았는가?
- 남은 가정의 확인 방법과 구조 설계에서 재검토할 결정이 명확한가?

## Scope

구조 설계로 넘기기로 한 세부를 탐색 누락으로 판정하지 않는다. 시장 조사·수치 목표·대안 수를 의례적으로 요구하지 않는다.
