# Specification Review

## Inputs

관련 상위 결정·실제 코드/인터페이스·상세 명세·위임된 선택·범위 제외. 공통 입력·판정·보고는 [리뷰 기준](../contract.md)을 따른다.

## Review Questions

- 정상·오류·경계 동작과 입력·출력·상태·부수 효과가 상위 요구에 맞는가?
- 중요 실패 후 남는 상태·사용자 결과·재시도/취소/복구가 구현자가 추정하지 않아도 될 만큼 명확한가?
- 호환성·데이터 전환·호출자 영향과 중요한 도메인 용어가 일치하는가?
- 사전 조건·행동·기대 결과와 필요한 근거로 수용 기준을 판단할 수 있는가?
- 중요한 미결정을 내부 재량으로 위장하거나 무관한 미래 범위를 끌어오지 않았는가?

## Scope

구현 순서·구체 명령·테스트 위치는 구현 계획의 책임이다. 축약 묶음 검토에서는 계획 프롬프트를 함께 적용하되 두 승인의 의미를 구분한다.
